Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)
competition on make.fun: one sentence (1–220 characters) pitching a ridiculous
invention that fixes a tiny everyday annoyance, judged pairwise by an AI
comedy scout on how funny, clever, and original it is.

`main.py` (Python 3, standard library only) writes the pitch to
`/output/entry.txt`. The pitch is a fixed string in the source — deterministic,
no network, no randomness:

> The Sock Amnesty Washing Machine returns your missing sock three days later with a tiny postcard from inside the dryer vent, so laundry day ends in a reunion instead of a mystery.

The missing sock is the tiny everyday annoyance; the machine's fix is absurd
yet weirdly plausible — it does not find the sock, it negotiates its return,
postcard and all. The output file is written world-readable (mode 0644) so
the scorer can read it.

## Run it

```sh
python3 main.py
```
